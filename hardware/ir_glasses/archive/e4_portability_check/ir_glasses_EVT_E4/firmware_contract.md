# E4 固件接入与首板约定

本文件是接口约定，不是已经编译、烧录或测试的固件。

| MCU 引脚 | 网络 | 行为 |
|---|---|---|
| PB2 / U9.21 | LED_ENABLE | 低：立即关 IR；上升沿：触发有时限的 IR 窗口；保持高不能无限延长本次窗口。 |
| PA8 / U9.28 | STATUS_LED_N | 低：D20 亮；高：D20 灭；复位时为输入，默认不保证点亮。 |
| PA4 / U9.15 | MUX_A0 | MUX 地址最低位，沿用 E2。 |
| PA6 / U9.17 | MUX_A1 | MUX 地址中间位，沿用 E2。 |
| PB0 / U9.19 | MUX_A2 | MUX 地址最高位，沿用 E2。 |
| PA5 / U9.16 | LED_SCLK | LED 移位时钟。 |
| PA7 / U9.18 | LED_SIN | LED 移位数据。 |
| PB1 / U9.20 | LED_LAT | LED 输出锁存。 |

SWD、UART、I²C 和 IMU 中断保持原定义。

## 上电

1. 在切换输出模式前，先写 PB2 的输出锁存为低、PA8 为高；使用推挽输出。
2. 保持 PB2 低，配置 TLC59283 并锁存全零，完成电源、参考及 IMU 初始化。
3. 初始化通过后，可将状态灯常亮表示已启动；慢闪约 1 Hz 表示运行，快闪约 4 Hz 表示故障。
4. 只在采样空闲窗口更新状态灯。背景采样及 IR 采样时均临时熄灭。

## 单通道采样

1. PB2 保持低，配置 MUX，等待实测确定的建立时间；采集 LED-off 背景。
2. TLC59283 只锁存一颗 IR-LED 为开启状态。
3. PB2 拉高，产生受硬件时间窗约束的发光；在稳定区采样。
4. 正常设计先按 100 µs 请求脉宽调试，结束后 PB2 拉低。切换通道前保持低，给定时电容充分复位时间。
5. 16 通道、50 Hz 全帧作为初始调试条件；最终建立时间、采样频率与占空比以实测定版。

U12 的 A 接 GND，B 接 3V3，CLR 接 LED_ENABLE。CLR 上升沿触发，CLR 拉低立即清除；
Q 经 U13 反相后驱动 TLC59283 的 BLANK。硬件时间窗约 0.2 ms 为典型估计，
首板先以 150–350 µs 作为调试检查窗口，不能将其当作保证的最坏上限。

## 故障注入与边界

- 在 IR 发光中暂停 CPU，并将 PB2 持续保持高：测量最终发光时间，确认硬件自行关断。
- MCU 复位、排线断连、上电/掉电过程中，检查是否出现意外发光。
- 快速重复触发仍能产生重复脉冲；本电路不独立限制长时间平均占空比。
- 看门狗、one-hot LED 选择和采样任务时序仍必须在固件中实现。
- GPIO 为高只表示发出请求；不要用 GPIO 电平代替实际 LED 电流或光输出测量。
- 状态灯不是独立电源指示灯，固件未运行时不亮不能单独判断电源故障。
- 实际眼距、光路、辐射输出和最坏故障条件尚待评估，时间窗电路本身不等于光学安全放行。

烧录交付仍需补齐：匹配 E4 的 HEX / BIN、SHA-256、烧录地址、option bytes、
SWD 读回校验及逐板测试记录。两块样板若由用户自行开发，可明确要求工厂交付空片。

## 主机上电顺序

主机 UART、复位和调试器输出应在本板供电关闭时保持高阻，待本板供电稳定后再驱动；SWD 使用板上 VTref。首板需测量断电时外部信号引起的反向供电，不能假设输入过压开关同时隔离了通信线。
