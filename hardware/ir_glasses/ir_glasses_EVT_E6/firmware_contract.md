# EVT E6 固件接口与采样时序

这是电路接口约定和首板调试基线，不是已编译或实测固件。E4 固件不能直接用于 E6。

## 选择接口

逻辑配置：`{led_id: 1..16, valid_mask: 1、2 或 3}`。默认 valid_mask=3，采集并输出两个相邻 PD。主机不指定任意 PD 组合。

- LED_ID 对应 D1..D16，锁存值 `1 << (led_id - 1)`；移位位序通过首板逐灯测试确认。
- PD 持续感光、16 路 TIA 持续工作；“激活两个 PD”表示只选取相邻两个 TIA 输出进入 ADC，未选择的 PD 不断电。
- U7 / ADC-A 固定选择奇数 PD；U8 / ADC-B 固定选择偶数 PD。A/B 不表示物理左右方向。
- PD 地址为 `(pd_id - 1) / 2` 整数除法，最低位为 A0/B0。每个 LED 只能使用下表对应关系。
- 单 PD 模式 valid_mask=1 或 2，仅发布相邻奇数或偶数 PD 的数据；仍同时转换两个核心。无效通路原始值、差分及 PD_ID 置0。
- 非法 LED_ID、valid_mask、多位 LED 掩码、SPI 错误、队列溢出或状态机异常均先关闭 LED，再报告错误。
- 切换地址或锁存 LED 位图前，必须使 LED_ENABLE=0、MUX_EN_N=1；地址稳定后 MUX_EN_N=0。

| D2 | PD3 | PD2 | 1 | 0 |
| D3 | PD3 | PD4 | 1 | 1 |

| D5 | PD5 | PD6 | 2 | 2 |

| D7 | PD7 | PD8 | 3 | 3 |
| D8 | PD1 | PD8 | 0 | 3 |
| D9 | PD9 | PD10 | 4 | 4 |
| D10 | PD11 | PD10 | 5 | 4 |
| D11 | PD11 | PD12 | 5 | 5 |

## ADC 初始化与读出

AD7386：AINA0/AINB0 使用；AINA1/AINB1 接地；SDOB 不接。两路模拟孔径由同一个 CS 下降沿确定，串行读出不改变采样时刻。

1. 上电首先确保 PB15 为低、ADC_CS_N 为高、MUX_EN_N 为高、状态灯灭。先写 GPIO 输出锁存，再配置方向和复用，TIM1 的 MOE/空闲电平配置必须保证 LED 请求默认低。
2. TLC59283 锁存全零。开启并稳定模拟电源、参考与 IMU；在3V3_A进入稳定工作范围后给 ADC 上电/参考至少20 ms等待；手册11 ms仅表示参考稳定到1%，精密测量需另行确认。
3. 使用独立 CS 事务写硬复位命令 `0xA0FF`，然后等待20 ms；写 CONFIGURATION1 `0x9000`，写 CONFIGURATION2 `0xA100`。
4. 配置结果：CH=0、SEQ=0、OSR=0、RES=0、REFSEL=0（内部 2.5V）、PMODE=0；SDO=1（单数据线）。初始化期间所有采样作废。
5. 按手册两次事务的寄存器读回流程验证配置；检查所读 12 位配置值为 `0x000` 和 `0x100`。
6. 常规数据事务发送 NOP，SPI MSB first。ADC 在 SCLK 上升沿更新输出，可用 CPOL=0、CPHA=1 的 SPI mode 1 接收；初始 SCLK=3 MHz（48 MHz 外设时钟 /16），每次持续 32 个时钟，先 A 的 16 位，再 B 的 16 位。CS 必须在整个 32-bit 事务保持低。

**流水线规则：本次 CS 下降沿采到的新值，在下一次 CS 事务中读回。** 初始一次返回值丢弃；必须用 pending 元数据关联上一次采样，不能把同一事务读到的数直接标成当前 LED/PD。常规采集期间不插入寄存器访问；若插入则清空流水线，重新预热。

## 定时基线

系统/外设时钟采用48 MHz。TIM3以1 MHz计数，每1250 µs产生一次时隙调度中断，16时隙构成50帧/秒。TIM1同样以1 MHz计数（PSC=47），ARR=999，采用OPM，每次只运行1000 µs。这样每个时隙留有250 µs调度余量，避免“1250 µs单次计数结束后再加CPU启动开销”造成帧率累积变慢。TIM3只请求CPU调度，不通过硬件触发TIM1；CPU停止时不会开启下一时隙。

主循环每次最多提交一个带序号的单次时隙令牌；只有上一时隙已完成、采样缓冲可用且配置合法才提交。TIM3中断只能原子消费这个令牌，禁止自行生成、续期或循环复用令牌。主循环失去进展而中断仍运行时，最多消费一个已排队令牌，随后保持灭灯；真正CPU halt时中断不会启动新时隙。看门狗只由主循环在确认有效进展后喂狗，禁止在定时器/SPI中断中无条件喂狗。测试必须分别覆盖主循环挂起与整颗CPU halt。

时隙中断先确认TIM1已停止、LED请求为低，再配置LED/MUX、准备SPI RX和两个比较事件表，最后启动TIM1。CH1输出ADC_CS_N；CH3N输出LED_ENABLE。每个时隙使用输出比较翻转模式及非循环DMA，初始CS为高、LED请求为低；TIM1内部OC3REF及CC3NP必须配置为使CH3N在200 µs上升、300 µs下降。MOE、OSSI/OSSR和OIS3N退出状态必须保持LED请求低。

每次重新装载时，先关闭CEN、比较DMA请求及MOE，将CNT清零；用强制输出模式建立OC1REF高和LED请求低的内部状态，再切换到翻转模式。禁止只依赖GPIO上拉或OIS来假定OCREF初值。CCR1/CCR3的输出比较预装载必须关闭（OC1PE=OC3PE=0），CCDS=0使DMA由各自比较事件触发，启用CC1DE/CC3DE；DMA写CCR使用16位宽度、内存自增、普通非循环模式。完成UG/状态清除后装载初始CCR和DMA表，再恢复输出及计数，避免UG提前消耗表或预装载让下一边沿延迟到周期末。

STM32C031的三个DMA通道明确分配如下，禁止再为SPI TX或UART申请第四通道：

| DMA | 请求 | 用途 |
|---|---|---|
| CH1 | TIM1_CH1 | 初值CCR1=100；非循环写入[124,250,274,65535]，最后值超过ARR，无后续采样边沿 |
| CH2 | TIM1_CH3 | 初值CCR3=200；非循环写入[300,65535]，点灯后必有灭灯边沿 |
| CH3 | SPI1_RX | 每次接收2个16位字，按A/B顺序保存；每事务重新装载NDTR=2 |

SPI TX发送两个16位NOP，使用CPU/短中断服务写入SPI数据寄存器，不使用TX DMA。UART TX使用中断及环形缓冲，初始921600baud。SPI使用3 MHz，32时钟约10.67 µs；48 MHz不能用整数二分频直接得到原约定的2 MHz，故修正为/16。采样边沿仍由TIM1硬件产生，SPI启动中断只负责读回上一次结果。发送字宽、DR访问宽度、RX阈值和OVR处理按RM0490实现。

TIM3调度丢失、TIM1仍忙、比较DMA未完成或SPI超时应关闭LED并丢弃该帧；不得紧接着补发多个时隙。将调度延迟纳入实测，正常最大延迟应小于50 µs，样本时间记录真实TIM1起点加采样偏移。TIM3周期避免帧率累积漂移，但不能保证CPU调度零抖动。这是实现约定，不是已经运行过的固件。

| 相对时隙开始 | 动作 |
|---|---|
| 0 µs | LED 保持灭；MUX 禁用，更新两组地址与 one-hot LED 位图，再启用 MUX |
| 100 µs | ADC_CS_N 下降，两个 PD 同时采背景；此事务读回前一时隙的亮灯值 |
| 102..113 µs | SPI 32 时钟读回前次结果，保存上一采样元数据 |
| 124 µs | ADC_CS_N 上升 |
| 200 µs | LED_ENABLE 上升，启动限时光脉冲 |
| 250 µs | ADC_CS_N 下降，两个 PD 同时采亮灯值；此事务读回本时隙背景 |
| 252..263 µs | SPI 32 时钟读回背景 |
| 274 µs | ADC_CS_N 上升 |
| 300 µs | LED_ENABLE 下降，结束约 100 µs 请求脉冲 |
| 1250 µs | 下一时隙，重复 |

CS 低窗口为24 µs，3 MHz /32 clocks占约10.67 µs，预留读出启动和完成余量。硬件采样边沿与 SPI 启动解耦；SPI 完成必须早于 CS 上升。按上述三通道分配实现后仍须验证DMA映射与中断响应；没有按期完成读出则丢弃整组，不挪动光采样边沿补读。

停止采集时先确保 LED 请求低，在最后一次亮灯采样转换完成后，再做一次 LED-off 的 CS/NOP 事务，取出最后一对亮灯结果；额外触发的背景样本丢弃。LED 硬件窗口的实际最小/最大值需首板测量；不得将 E4 典型 0.2 ms 当作保证值。

上述等待时间是调试基线。满量程通道切换、最大环境光、饱和恢复和温度变化下测量建立时间后才可缩短。若 50 µs 亮灯稳定时间不足，先调整窗口并复核 LED 时间保护，不得把未稳定结果作为有效采样。

## 数据约定

每个结果含：协议版本 E6、frame_seq、slot_seq、LED_ID、PD_A_ID、PD_B_ID、采样时刻、dark_a/dark_b、light_a/light_b（uint16）、delta_a/delta_b（int32）、valid_mask 与故障标志。

- `delta = int32(light) - int32(dark)`，允许负值，禁止 uint16 下溢。
- 帧时间应来自实际采样事件，读取完成时间单独记录或不输出。
- 默认不发送每个 SPI 事务的未经配对数据。样本记录采用 `firmware_interface.h` 的40字节字段布局，整数按小端序显式编码；外层封包、长度、CRC与重同步由固件实现并与主机一致。
- 无校准时，TIA 端电压估算 `code * 2.5 / 65536 * 1.5`；校准后的增益/偏置按每个 PD 和 A/B 采集路径保存。
- 100 kΩ 跨阻下，ADC 一码对应约 0.572 nA 的输入电流增量，这是量化步长，不是可保证检测灵敏度。

## UART 吞吐预算

40字节/时隙 × 16时隙/帧 × 50帧/秒 = 32,000字节/秒，未计外层帧头与CRC。若每帧增加12字节，合计32,600字节/秒；8N1需要至少326,000bit/s。默认主机UART采用921600baud；460800baud亦有约29%的名义带宽余量，须实测连续传输和缓冲占用。115200baud无法传输完整50帧/秒数据，需降帧率或改变已约定的输出内容。不得用丢失样本维持表面帧率。

`sample_seq` 每个完成配对的时隙递增一次。`light_time_us` 为亮灯采样的真实CS下降沿时刻，uint32约71.6分钟回绕，主机按模2^32展开。单PD模式未选通发布的通路原始值、差分及PD_ID置0，valid_mask仅保留有效通路位。保留字段置0；饱和、尚未建立或流水线错误样本不得标为有效。

## 保护与兼容

保留硬件脉冲时间窗。CPU 停止后不能再启动下一时隙；若停止在高请求期间，由 U12 限制本次脉冲。该保证依赖上述单时隙 OPM/非循环 DMA 配置，首板须分别测试 CPU halt、死循环与高电平卡死；原单稳态不能阻断仍在反复跳变的自主 PWM。看门狗、one-hot、长时间平均占空比管理仍由固件负责；快速重复触发不会被单稳态独立限制。主机掉电时通信/调试信号保持高阻，SWD 使用板上 VTref。首板必须测量 LED 电流和实际 CS 边沿，不能用 GPIO 电平推断光输出。

## U14 自动重试版本

U14 按用户要求使用 TPS259470ARPWR（C3662799），与原 TPS259470LRPWR 的 RPW 10 引脚封装兼容；本版 U19 控制 EN/UVLO，OVLO 接地，U14 的限流电阻保留，C38 改为 22nF。热保护后，器件在冷却并等待内部重试延时后自动恢复，持续故障时可能反复断电和重启。固件每次复位均须保持 LED 关闭，初始化完成前不得恢复旧采样请求；U12/U13 的 LED 脉宽限时电路独立保留。首板须在限流电源下验证故障、恢复及反复重启时的灭灯默认态。依据：TI TPS25947 数据手册 SLVSFC9C，第4节及7.3.8节，https://www.ti.com/lit/ds/symlink/tps25947.pdf 。

## J1及上电更新

J1仍为GUOCONN 0.5K-AS-5PWB-RW，输入现在先经过U18 TPS2553DRVR低电流限流，再进入U14。U19 TPS3702CX33DDCR负责较小滞回的过压检测。C38改为22nF，常规启动典型约36ms。主机电源设计范围3.3V±3%、正确极性，不再依赖主机≤0.30A限流来保护下游持续过载；热插拔瞬态和实际电源范围仍须验证。详见connector_and_power.md。

参考：STM32C031数据手册及[RM0490参考手册](https://www.st.com/resource/en/reference_manual/rm0490-stm32c0x1-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)。启动等待从MCU复位释放后计时；首板应核对慢斜率供电期间BOR/POR和LED状态。

## P3 模拟建立约束

U16/U17采用TLV9062，输入网络改为100Ω/330pF。保持MUX切换后100µs和亮灯后50µs等待，保持CS高电平至少5µs后才允许下一次下降沿（包括停止时的flush事务）。现有100/124/250/274µs边沿满足该约定。5µs是按典型宏模型加余量的板级调试下限，不是芯片保证；首板通过后才可缩短。不启用连续4MSPS、最短110ns采集窗口或内部高速过采样；这些模式必须重新验证输入驱动。建立误差以校准后的稳态均值为参考，不能混淆失调/增益误差、随机噪声和动态残差。
