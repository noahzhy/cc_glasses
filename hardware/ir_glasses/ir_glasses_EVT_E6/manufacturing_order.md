# EVT E6 制板与贴片交接

本包是四层原型板制造资料。设计静态检查已通过，工厂 DFM、备料和首板功能实测尚待完成。使用载框 CAM 制造，勿将裸板和载框层混用。

| 项目 | 要求 |
|---|---|
| 制板文件 | `carrier/JLC_upload.zip` |
| 贴片 BOM | `bom_jlc.csv`；详细采购信息见 `bom_EVT_E6.xlsx` |
| 贴片坐标 | `carrier/manufacturing/positions_jlc.csv` |
| 层数和板厚 | 4 层，1.6 mm |
| 铜厚 | 外层 35 µm，内层 15.2 µm；层叠见 KiCad 工程 |
| 表面处理 | 沉金 ENIG |
| 阻焊和字符 | 绿色阻焊，白色字符 |
| 最小线宽 / 间距 | 0.10 / 0.10 mm |
| 最小过孔外径 / 钻孔 | 0.35 / 0.15 mm；须选择支持 0.15 mm 钻孔的工艺并确认费用 |
| 过孔处理 | 正反面盖油；按工厂套准能力复核，未要求树脂塞孔 |
| 铜到板边 | 不小于 0.30 mm |
| 贴装面 | 正面；167 个器件/板 |
| 不贴装位置 | J2 Tag-Connect 裸焊盘、TP1–TP12 背面测试点、载框 Mark 和定位孔 |
| 分板 | 沿用 E4 工艺边与实心连接桥；治具支撑铣断，不手折、不 V-cut |
| 烧录 | 本包无可烧录固件；按空片装配 |
