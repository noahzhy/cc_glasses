# EVT E6 P1 历史修复记录

**此文记录2026-09-16的P1修复。当前P2已替换U19、分压、控制路径和相关布局，当前结论请见 production_refinement_report.md；以下数值及旧检查数量仅作历史记录。**

本次针对量产准备复核中发现的设计问题修改电路及布局。仍是 EVT 首板设计：静态检查不能替代首板和工厂放行。

| 原问题 | 本版修改 | 验证边界 |
|---|---|---|
| J1 单触点 0.4 A，原 U14 约 0.538 A 限流不足以约束持续负载电流 | 新增 U18 TPS2553DRVR，置于主电容和 U14 之前；110k 设置约 243 mA 典型限流 | 含电阻误差和温漂的静态计算约 209～282 mA；热插拔、短路瞬间及触点温升待实测 |
| U14 原 OVLO 分压存在回到 3.3 V 仍保持断电的情况 | 新增 U19 TPS3700DSER 控制 OVLO，R19 改为 2.43k | 输入要求 3.3 V±3%；静态门限覆盖正常范围；动态恢复、过冲和欠压重启待实测 |
| OVLO 恢复旁路 U14 的 dVdt | 保留 U18 上游持续限流；C38 改 22 nF 降低常规启动浪涌 | C38 不承诺限制 OVLO 恢复浪涌；两种情况单独列入测试 |
| STM32C031 只有三个 DMA 通道，原接口资源未落实 | 两个定时比较 DMA 加一个 SPI RX DMA；SPI TX 与 UART 使用 CPU/中断；SPI 改为 48 MHz /16 = 3 MHz；主循环提交一次性时隙令牌，ISR不得自行续期 | 交付接口约定；无可烧录固件，需示波器验证边沿和 CPU 停机行为 |
| 密集控制区布线与去耦位置 | MUX_B1 改到空闲 PD0（U9 第 38 脚），MUX_EN_N 改到 PB0（19 脚）；IMU_INT 改到 PB2（21 脚，EXTI2），TP11 移近 IMU；PC7/PB8/PB3 留空；C37 移近 U14；C2/C45 调整位置和方向以接通电源与主地；接口约定同步更新 | 按 STM32C031C6 官方 LQFP48 引脚表核对；连接及间距由本版 ERC/DRC 检查 |
| 采购缺口表未充分反映量产备料 | 显示 ADC 仅 8 件、U19 73 件库存快照，以及实际数量、损耗、MOQ、贴片库存待确认 | 未采购、未锁库存，不代表可立即量产 |

保留用户指定的 TPS259470ARPWR、GUOCONN J1；保留 E4 光学器件位置、方向、板框和安装结构。新增保护器件采用本地专用封装：U18 为带 EP 的 DRV WSON，U19 为无 EP 的 DSE WSON。

主机电源必须符合本版 3.3 V±3%、正确极性要求。U18 的输入限制使 U14 单器件高压能力不再代表整板能力；不得反接或把超过 5.5 V 当作允许输入。板前端短路、器件失效及 ESD 瞬态不属于持续限流计算的保证范围。

实际检查结果见 `erc.json`、`drc.json`、`power_protection_validation.json`、`manufacturing_validation.json` 和 `release_checklist.csv`；物理测试均按 `first_board_tests.csv` 留为待完成。原复核目录 `../EVT_E6_preproduction_audit/` 保留为修复前历史证据。

GPIO 引脚依据：[ST STM32C031x4/x6 数据手册](https://www.st.com/resource/en/datasheet/stm32c031c6.pdf)。

## 本版重新检查结果

- KiCad 10.0.6：主板 ERC、DRC、未连接与原理图一致性均为 0；载框 DRC/未连接均为 0。
- 设计与光学/网络检查 1457 项、载框保留检查 13676 项、CAM/BOM/CPL/本地库检查 1454 项通过。
- J1 封装/线序检查 24 项、电源保护静态检查 97 项通过。
- 492 个过孔已核对钻孔边缘到贴片/测试焊盘的距离；最低约 0.100 mm。工厂阻焊对位和盖油能力仍须确认。
- 167 个正面贴装器件、43 类 BOM；9 页原理图、两页贴好片示意图和载框生产包已重新生成。

这些结果对应本包文件及 SHA256SUMS.txt，不包括尚未完成的首板测试、可烧录固件或工厂量产放行。
