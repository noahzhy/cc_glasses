# EVT E2 硬件与投产前审查

审查日期：2026-09-08。对象：当前 EVT E2 单板、载框、原理图、122 位号 BOM/CPL 及已打包制造文件。计划数量仍为 5 块 PCB、其中 2 块贴装。

**结论：未发现本次核对范围内的明显引脚接错、PD 极性错误或网络缺连，但不能直接按量产版放行。建议先处理复位保护与两处过孔间隙，明确 LED 故障关闭策略，再完成两块 EVT 首板验证。**

本次只进行审查并新增报告，没有修改冻结 PCB、原理图或生产 ZIP。以下“建议修改”尚未实施。没有实物、示波器测试、工厂 DFM 或库存确认结果。

## 优先处理的问题

## 还值得改进的布局

这些属于布局与模拟验证风险，不是已证实的功能失效。

| 项目 | 当前测量/连接 | 建议 |
|---|---|---|
| 局部去耦 | U2.4–C3.1 直线距离约 4.81 mm；U3.4–C4.1 4.24 mm；U4.4–C5.1 3.00 mm；U5.4–C6.1 4.24 mm。U9.6–C17.1 约 3.89 mm。 | 对应 100 nF 尽量移到电源脚附近，缩小电源脚—电容—地的回路。上述是焊盘中心直线距离，不是供电走线长度，也不是独立合格判据。 |
| ADC 回流 | U9.7 的 VSS/VSSA 接 GND；C29/C30 的 ADC 滤波电容接 AGND；NT1 位于 (92,67) mm，距 U9.7 约 14.34 mm，距 C30 地端约 24.56 mm。 | 检查模拟跨分区信号的回流路径，优先使 ADC 输入滤波和参考去耦就近回到 ADC 参考地。不要仅因使用了 AGND/GND 网名就认为已经隔离噪声，也不要未经分析随意加多个地桥。 |
| TIA 动态范围 | 理想输出约为 1.65 V + 光电流 × 100 kΩ；忽略输出摆幅限制时，正向剩余量程约 16.5 µA，实际更低。理想反馈 RC 为 2.2 µs、对应约 72 kHz 极点。 | LED-off 背景扣除不能恢复已经饱和的模拟输出；检查强环境光、镜片反射下的余量。RC 数值不能替代完整环路和采样建立测试。 |
| 光学结构 | IR11-21C 为 top-view 出光，PD15-21B 为 top-view 接收。平面内旋转是封装方向调整，不改变朝向 PCB 法线的主要光轴。 | 需确认整板佩戴朝向、眼距、目标反射路径、遮光结构和透光窗口。沿镜框切向摆放本身不证明光束已经指向所需眼部位置。 |

## 首板表需要补充的条目

下列内容用于修订后续测试流程，不能视为 E2 已通过：

| 测试 | 方法与记录 |
|---|---|
| 上电 LED 锁存 | BLANK 保持高，先移入并锁存全零，再允许输出。测试慢上电、快速断电再上电与重复复位。 |
| 故障发光 | 在 LED-on 区间暂停 CPU、模拟任务卡死，测 BLANK 和 LED 电流持续时间。首先在非佩戴夹具中进行。现版无独立限时，不把普通上拉当作故障关闭保证。 |
| NRST 抗扰 | 记录 J1/J2 操作前后的 NRST 波形、复位计数、启动恢复；电容/ESD 修改后重测低电平驱动和释放。 |
| 模拟噪声定位 | 对照 LED 完全关闭、扫描、UART 连续发送、IMU 运行四种状态的 ADC/TIA 波形，区分光串扰与电气耦合。 |
| ADC 建立/标定 | 上电执行 ADC 校准；覆盖 MUX 大信号通道跳变，检查前后样本差异，确定需要的等待时间、采样周期和是否丢弃首样。 |
| 发射约束 | 记录逐路峰值电流、脉宽、帧率，以及故障态可能同时开启的路数。光学适用性依据实物结构和测量，不能仅凭 20 mA 电流下结论。 |

## 建议执行顺序

1. 修订 NRST 近端滤波/入口保护，移开 D14/D5 两颗近孔过孔，同时整理局部去耦。
2. 确定 LED 故障关断方案与电源/排线接口边界；若改硬件，建立新修订并重新导出全部生产资料。
3. 完成工厂 DFM、齐料、自备入库与首件方向确认后，只先生产已计划的两块 EVT 贴装板。
4. 做电气、故障态与实际光路测试，冻结固件/参数和工厂测试阈值后再决定量产。
