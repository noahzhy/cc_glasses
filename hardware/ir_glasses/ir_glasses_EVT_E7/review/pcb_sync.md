# 原理图到 PCB 同步记录

E7 为独立的唯一工程及含 carrier 的单一 PCB。E6 文件保持历史状态，不应使用 E6 制造文件生产 E7。

| 项目 | E7 处理 |
|---|---|
| U9/9、C11/1、C47/1 | PCB 焊盘网络均已同步为 `3V3`，与整改后原理图一致。 |
| C24、C45、TP5、TP6 | 原理图、PCB 和 BOM 均删除；其余器件不重新编号。 |
| 保留引脚 | 522 个原理图引脚与 PCB 焊盘网络逐项匹配。 |
| 器件装配面 | 全部 164 个电气器件在 F.Cu，包括测试点。 |
| 层数和板厚 | 四层、1.6 mm；不增加铜层。 |
| 过孔制造约束 | 所有实际过孔孔径 ≥0.20 mm、外径 ≥0.40 mm；工程规则同步，单边环宽 ≥0.10 mm。 |
| 光学、接口和机械 | 固定器件坐标、方向、板面及原始 Edge.Cuts 逐项对照。 |
| U1 丝印 | 仅调整第一脚三角标记位置，避免覆盖邻近焊盘；本地封装库同步。焊盘不变。 |
| D17/D18/D19 装配位号 | 改用可编辑的 F.Fab 位号字段，字号统一；调整 D17/D18 位号位置以消除装配图重叠。本地 SOD 封装库同步，焊盘、器件位置和型号不变。 |

焊盘网络匹配不等于布线完成。剩余未连接项及 DRC 状态以根目录 `drc.json` 和 `review/validation.json` 为准；后者未通过时不得视为可生产设计。
