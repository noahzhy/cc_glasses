# E7 3D assembly previews

Generated from the current E7 PCB with KiCad 10 native ray tracing. Images: EVT_E7_top.png, EVT_E7_bottom.png, EVT_E7_angle.png.

Rendering overrides KIPRJMOD to the project's libraries directory so the board's existing ../models references resolve to the bundled models. No PCB geometry, placement or electrical data was changed. These are visual assembly previews; simplified component models are not dimensional certification.
