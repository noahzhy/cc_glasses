# EVT E2 制造与贴装说明

加工数量：5 个载框，每个含 1 副眼镜 PCB；其中 2 副正面贴装，另 3 副保持裸板。5 副均由工厂用支撑治具铣断去框后交付。版本必须为 **EVT E2 / PD15-21B/TR8**。

## PCB 工艺

| 参数 | 要求 |
|---|---|
| 材料与层数 | 四层刚性 FR-4 |
| 成品厚度 | 名义 1.6 mm，按工厂标准公差 |
| 铜厚 | 外层 1 oz，内层 0.5 oz，按工厂标准工艺确认成品铜厚 |
| 表面处理 | ENIG 沉金 |
| 阻焊 / 丝印 | 绿油 / 白字 |
| 层序 | F.Cu、In1.Cu、In2.Cu、B.Cu |
| 阻抗控制 | 不要求 |
| 最小线宽 / 间距 | 0.15 / 0.15 mm，具体局部规则及铜边界以 Gerber 和工程为准 |
| 装配面 | 仅正面 F.Cu / Top；背面不贴元件、不开贴装钢网 |
| 成品外包络 | 132.305145 × 51.955477 mm，按 Edge.Cuts 中心线定义 |
| 载框外包络 | 152.305 × 71.955 mm，按载框 Edge.Cuts 中心线定义 |

KiCad 板文件和 Gerber Job 已记录四层叠层与 ENIG。内部名义叠层参考标识 `JLC04161H7628` 仅表示常规 1.6 mm 四层叠层，不要求定制精确压合，也不要求海外站同名叠层。请工厂按国内标准 FR-4 四层叠层确认材料、介质及铜厚，保持名义总厚度和上述制造规格。

Gerber Job 的 Size 统计包含 0.05 mm 的板框线宽，X/Y 会比机械中心线包络各大约 0.05 mm；这不是成品外形放大。最终轮廓按 Edge.Cuts 中心线和机械图解释。

## 文件配套与钻孔

| 文件组 | 用途及配套 |
|---|---|
| `carrier/manufacturing/` 中 `ir_glasses_carrier-*` Gerber 与 `*PTH.drl`、`*NPTH.drl` | **本批 PCB 制作输入**，保留载框及 8 个实心桥，两份钻孔均须导入 |
| `carrier/positions_jlc.csv` + `material_freeze/bom_smt_all_122.csv` | 本批贴片匹配输入，完整覆盖 122 位号；J1 需人工匹配已接收的自备物料 |
| `manufacturing/` 中 `ir_glasses-*` Gerber 与 `*PTH.drl`、`*NPTH.drl` | 成品轮廓参考 / 不带载框工程版本，两份钻孔成套，不与载框文件混合投产 |
| `carrier/carrier_review.svg`、`carrier_design.md` | 工艺边、定位、连接桥和二次分板审核 |
| `assembly_front.svg`、`optical_assembly.pdf`、`optical_placement.csv`、`schematic.pdf` | 首件位号、PD/LED 极性、实际旋转角及网络对照 |

钻孔导出采用毫米制 Excellon，金属化与非金属化孔已分离。请将所选制造目录的 **`*PTH.drl` 与 `*NPTH.drl` 两份一起导入**：PTH 文件为金属化电路过孔，NPTH 文件为非金属化机械孔；载框四角 Ø2 mm 孔及 J2 机械定位孔均在 NPTH 文件中。不得漏导任一文件，也不得将 NPTH 按金属化加工。审查目录中的旧参考文件不属于制造输入，不与当前分离钻孔重复导入。

贴片坐标沿用 KiCad 原点，单位 mm，**PosX = PCB X，PosY = -PCB Y**，因此 Y 为负数是正常坐标约定。载框没有平移产品或元件，成品/载框 CPL 数值一致；不应将元件坐标再次加上工艺边偏移。正面角度按导出 Rot，工厂元件库零度方向可能不同，必须通过首件图核对极性和实际外观。4 个定位孔与 3 个 Mark 不在 122 行 CPL 内，工厂 CAM 从载框文件识别。

另提供 `positions_jlc.csv`，将原生坐标转换为 Designator、Mid X、Mid Y、Layer、Rotation 表头，单位仍为 mm，全部为 Top，数值和角度不变。格式依据[嘉立创 BOM 与坐标规范](https://www.jlc.com/portal/server_guide_48022.html)。完整 BOM 加上数量与嘉立创元件编号字段，J1 的编码留空待自备料匹配。

## 载框、工装与分板

四周连续 8 mm 工艺边，成品最大包络至工艺边内侧至少 2 mm；8 个实心桥名义宽 3 mm，分布为上沿 4 个、两侧各 1 个、下沿各 1 个。四角 Ø2 mm 非金属化定位孔中心距外边各 4 mm。3 个不对称正面 Mark 的铜径 1 mm、阻焊开窗径 2 mm，不开锡膏。

初次铣槽只加工载框 Edge.Cuts，保留实心桥。贴装与检验后用下支撑治具承托双眼薄框和上方电子区，再沿审核图红色路径铣断，按成品原始轮廓精修。红色分板路径位于 Dwgs.User，不属于初次 Edge.Cuts。**不使用 V-cut、手折或斜口钳剪桥。**刀具补偿朝废料侧，不能为去桥扩大双眼开孔或削薄 3.0 mm 镜框。

分板切口内侧保留至少 0.30 mm 铜间隙，连接桥不带电连接。请确认支撑方式、刀具半径、铣断顺序、轮廓公差以及夹具不会压住 PD、IR-LED、J1 和中央 IMU。载框提高夹持条件，但不替代工厂的薄框支撑/分板治具确认。公开工艺依据：[嘉立创加工能力](https://www.jlc.com/portal/vtechnology.html)、[定位孔与 Mark 规则](https://www.jlc.com/portal/server_guide_14565.html)。

## 贴装与物料

- 每板 122 颗正面元件、410 个器件铜焊盘；焊点最终计费口径由工厂核对。25 类完整 MPN，禁止仅按阻容数值自动替换。
- PD1–PD16 为 **Everlight PD15-21B/TR8 / C2921391**，两个 1.0 × 1.5 mm 焊盘，中心距 2.6 mm；**1 脚阳极接 AGND，2 脚阴极接 PD_IN**。新器件不能沿用旧 PD15-22B 的 4 脚位或极性设定。请逐颗对照装配图中的旋转角。
- D1–D16 为 Everlight IR11-21C/TR8；LED 和 PD 沿框边并排，型号、极性和方向不能互换。光学窗口应保持洁净，装配处理按原厂回流和包装条件。
- J1 为 **TE 2492111-5**，用户自备选择已确定，净用 2 颗，建议备 5 颗；实际损耗、包装方向、内部物料编码和入库接收尚待确认。
- 两块板均装 100 kΩ / 22 pF。220 kΩ 和 470 kΩ 仅为另购调试备件，**不装入本批首板**。
- J2 是 Tag-Connect 调试焊盘，TP1–TP12 和 NT1 为板上特征，不采购、不贴装。载框孔和 Mark 同样不计入器件 BOM。

## 验收状态

本版已完成原生 ERC、DRC、未连接和原理图/PCB 一致性检查，均为零；载框验证元件位置、网络和 CPL 未改变。检查配置与结果见随包 JSON 报告。光学焊盘到成品板边、钻孔到贴片焊盘、分板路径到铜等几何结果随报告提供，请工厂进一步结合实际加工公差确认阻焊、锡膏、钻孔及铣边 DFM。

最新几何核对中，光学铜焊盘到成品板边最小约 0.500 mm，全部贴装焊盘到板边最小约 0.440 mm；过孔钻孔与贴装铜焊盘没有几何重叠，最小孔缘到焊盘间隙约 0.052 mm。该最小值仍需工厂结合钻偏公差、阻焊及锡膏开口核对，不能把“无重叠”解释为已验证实际加工公差。

国内实时库存、平台损耗、自备料入库、正式报价和工厂 DFM 尚未确认。供货未知不等于确定缺货，按 `procurement/` 清单实际配单。首件贴装方向、工装适用性、电气功能与物理光学性能尚未实测；工厂外观检查不代替 `first_board_test.md` 中的首板验证。
